# 🦚 Shree Krishna Neon Outline Sketch using Python

A creative coding project that draws a divine neon outline sketch of **Lord Krishna** with live cursor animation using Python's **Turtle Graphics** and **OpenCV**.

---

## ✨ Features
- 🖌️ **Live Cursor Animation:** Watch the turtle cursor trace the outline stroke by stroke.
- 🎨 **Adaptive Color Sampling:** Retains the original neon blue, peacock feather greens, and golden ornament hues directly from the source image.
- ⚡ **Optimized Vector Curves:** Uses morphological skeletonization to produce clean, continuous curves without jagged polygon artifacts.

---

## 🚀 Quick Setup & Run (All Steps in One Go)

Copy-paste this entire block in your terminal to set up, install dependencies, and run the project:

# 1. Clone the repository
```
git clone [https://github.com/Gracyclub/shree-krishna-python-sketch.git](https://github.com/Gracyclub/shree-krishna-python-sketch.git)
```

# 2. Navigate into the directory
```
cd shree-krishna-python-sketch
```

# 3. Install required packages
```
pip install opencv-python numpy
```

# 4. Make sure your reference image 'KANHA.JPG' is placed in this folder, then run:
python kanha.py
